1. Briefly summarize The Gaming Room client and their software requirements. Who was the client? What type of software did they want you to design?

The Gaming Room requests a web-based multiplayer game that will have several players who will form teams. Each game will consist of several rounds where each team will try to guess what the game is drawing within 30 seconds to win that round, should that team fail then the other teams are given a brief chance to make a guess.
